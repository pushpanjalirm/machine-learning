# Regularization Exercises

This folder contains a script that runs the Regularization lab exercises (Linear Regression, Ridge, Lasso, ElasticNet) on the Boston Housing dataset found in the repository.

Files
- run_regularization.py : main script to run exercises and save plots to outputs/

Usage
1. Ensure required packages are installed (see repository requirements.txt). At minimum: scikit-learn, pandas, numpy, matplotlib, seaborn.
2. From the workspace root run:
   python Regularization-Exercises/run_regularization.py

Outputs
- Regularization-Exercises/outputs/ : contains saved coefficient plots and summary plots.
